# 论文结构模板

> 由 `manuscript-format` 使用。动手前**先列出全部方案让用户选**（可组合、可修改），选完再确认，不要只丢一句"这样是否合理"。

## 确认流程（先定架构，再写正文）

1. **用户提供了模板 / 大纲** → 严格按用户模板，不自行增删章节。
2. **用户未提供** → 把下方「可选结构方案」**完整列出来**让用户选；用户不选 → 根据主题情景推荐一套，**询问用户"这样是否合理"**；用户改动就按改后的。

## 可选结构方案（动手前列给用户选）

### 方案 A：学位论文（毕业论文 / 硕博学位论文）

1. 封面 / 标题页 —— 题目、作者、院系、导师、日期
2. 中文摘要 + 关键词
3. Abstract + Keywords（**与中文摘要分开确认**，可单独去掉）
4. 目录 —— 自动生成，抓标题层级
5. 正文：
   - 第 1 章 绪论（研究背景与意义 → 国内外研究现状 → 研究内容与方法 → 论文结构安排）
   - 第 2 章 相关理论与技术基础
   - 第 3 章 研究设计与方案
   - 第 4 章 实验 / 实证结果与分析
   - 第 5 章 讨论（可选，或并入第 4 章）
   - 第 6 章 结论与展望
6. 参考文献 —— GB/T 7714，一条一行、悬挂缩进
7. 附录 —— 数据、代码、补充材料（可选）
8. 致谢 —— 可选

### 方案 B：期刊论文（投稿标准版）

1. 标题 + 作者信息
2. 摘要 + 关键词（按期刊要求决定是否附英文 Abstract）
3. 正文：引言（问题 + 现状 + 缺口）→ 方法 → 结果 → 讨论 → 结论
4. 参考文献 —— 按目标期刊格式（GB/T 7714 / APA / IEEE / Nature）
5. 附录（可选）+ 致谢（可选）

### 方案 C：独立综述（综述类投稿 / 毕业综述）

1. 标题 + 摘要 + 关键词
2. 引言：背景与问题
3. 主体：主题综述（按时间线 / 按流派 / 按问题拆分小节）
4. 综合评述：不同观点、方法、证据的比较
5. 研究缺口：现有研究的空白
6. 本文定位 / 展望：综述的贡献与未来方向
7. 参考文献

### 方案 D：课程论文 / 期末论文（简版）

1. 标题 + 姓名 / 学号（可选）+ 摘要（可选）+ 关键词（可选）
2. 引言：问题背景与目的
3. 正文：论点分节展开（通常 2~3 节）
4. 结论
5. 参考文献

### 方案 E：开题报告

1. 封面 / 标题页（题目、专业、导师、日期）
2. 研究背景与意义
3. 国内外研究现状（文献综述）
4. 研究内容与目标
5. 研究方法与技术路线
6. 进度安排
7. 参考文献 / 预期成果与创新点

### 方案 F：英文 SCI / 国际期刊论文（IMRaD）

1. Title + Author list + Affiliations
2. Abstract（单段，按期刊词限）+ Keywords
3. 1 Introduction：背景 → 缺口 → 本文贡献（列表式 3~4 条）→ 结构安排
4. 2 Related Work（或并入 Introduction）
5. 3 Methodology：问题定义（含符号表）→ 方法框架 → 关键模块
6. 4 Experiments：设置（数据 / 基线 / 指标）→ 主结果 → 消融实验 → 分析讨论
7. 5 Conclusion（含 limitations）
8. References —— 按目标期刊格式（APA / IEEE / Nature），一条一行悬挂缩进
9. 附录 / 补充材料（可选）

> 英文基线、语言规范、Cover Letter 与审稿回复见 [`../../references/english-writing.md`](../../references/english-writing.md)。
