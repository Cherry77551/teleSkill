# 示例：数据图表

> 展示：先问清再动手，用 `plot.py` 参数化出图，给脚本 + 图 + 图注。

## 用户输入
我有一份实验数据，帮我画个图看看趋势。

## 技能输出
好的，先确认几个细节再动手 (๑•̀ㅂ•́)✧

**1. 数据在哪？** 是 CSV / Excel / 还是直接贴表格文本？
**2. 要传达的核心结论是什么？** （比如"温度越高效率越低"还是"三组之间有显著差异"）
**3. 输出格式？** Word 里插图用（PDF 矢量图）还是直接看就行？
**4. 要不要表格？** 有些数据用表更清楚，我可以一起给。

数据发给我我就开干～

---

### （用户发了 CSV：temperature,efficiency 两列）

收到，我先把数据过一遍再画图。

**数据概览**：
- 共 10 组数据，温度范围 25–85 °C，效率范围 22.1%–18.3%
- 无缺失值，量纲完整
- 结论方向：温度升高，效率下降（负相关）

我用折线图来展示趋势（x=温度，y=效率），矢量 PDF 输出。用脚本 `plot.py` 生成，可复现：

```bash
python scripts/plot.py data.csv --x temperature --y efficiency --kind line -o figure.pdf
```

**图注（caption）**：
> 图 1 钙钛矿太阳能电池效率随温度变化曲线。测试条件：AM 1.5G 模拟太阳光，温度范围 25–85 °C，每 10 °C 一个测点。效率随温度升高近似线性下降，温度系数约为 –0.076 %/°C。

图和脚本都在附件里，有要调整的地方（配色、加误差棒、换图类型）随时说～
