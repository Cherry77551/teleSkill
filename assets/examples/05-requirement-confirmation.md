# 示例 05 · 需求确认选择题交互（可点击提问全过程）

> 场景：用户只给主题"帮我写一篇关于智算中心调度的论文"。以下展示如何用**可点击的选择题**逐项确认需求（优先调用平台提问工具；每项标注"若不选择或无要求"的推荐做法；语言默认中文不出现）。完整题目与选项措辞以 `SKILL.md` 第二步为准，本示例演示交互形态。

## 第 1 题 · 输出格式（完整样例）

- 问题：论文以什么格式交付？
- 选项：A. Word 文档（可编辑）　B. PDF（定稿）　C. LaTeX　D. HTML　E. 其他（请补充）
- 说明：若不选择或无要求，推荐按您使用 Word 文档（可编辑）处理。

## 第 2 题 · 摘要（完整样例，注意必含"不要摘要"选项）

- 问题：需要哪种摘要？
- 选项：A. 中文摘要 + 英文摘要（Abstract）　B. 仅中文摘要　C. 仅英文摘要　D. 不要摘要
- 说明：若不选择或无要求，推荐按您使用"中文摘要 + 英文摘要"。

## 第 3–7 题（同形展开，选项与推荐值见 SKILL.md 第二步）

- **第 3 题 · 附带要素**：逐项"要 / 不要"多选；表格须追问表类型（A. 全线表格　B. 三线表——未注明推荐按您使用全线表格）；插图、目录、公式、封面、附录逐项问。
- **第 4 题 · 排版规格**：中文字体 / 西文字体 / 正文字号 / 标题字号 / 页边距 / 行距逐项选择，每项标推荐值；已给目标期刊模板则以其为准。
- **第 5 题 · 论文结构**：学位论文 / 期刊论文 / 独立综述 / 课程论文 / 开题报告 / 自带模板，可多选组合。
- **第 6 题 · 篇幅**：按字数 / 按页数 / 不做要求；选中前两项后再请用户报数值或范围，一般不严格卡死。
- **第 7 题 · 资料来源**：A. 有现成资料　B. 请联网搜集并逐条标注来源　C. 先给检索式 + 待检索清单。

## 收尾（复述 → 预估 → 点头）

确认完七题后，把全部要求汇总成清单复述，例如：

> 已确认：Word 文档；中文摘要+英文摘要；含表格（全线表格）、目录、公式；正文宋体小四、标题黑体、全文纯黑、题目与章标题居中、目录独立一页；结构采用学位论文式；篇幅按字数（约 8000~10000 字）；资料来源由我联网搜集并逐条标注。
> 预计完成时间约 2 小时。以上还有什么需要修改的地方吗？没有的话请点个头，我将开始写。

**等用户明确点头后**再动笔；用户提修改先改再重新确认。

## 模板模式（用户已提供模板 docx 时）

字体字号等**模板已定项**改为确认题，不让用户重新盲选：

- 问题：检测到模板要求"正文宋体小四、标题黑体三号、页边距上下 2.5cm 左右 3cm"，是否按模板执行？
- 选项：A. 按模板执行（推荐按您使用模板值）　B. 改用其他（请补充）
- 说明：模板未定义的项（摘要、附带要素、篇幅等）仍按第 1~7 题原样出选择题；模板画像清单（学到的版式、将删除的示例内容、被覆盖的默认项、不被覆盖的学术底线项）逐项复述，点头后才生成。
