# 文献综述

综述不是把读过的文献排成一列，是围绕一个研究问题，把已有证据组织成一条能回查的论证。综述的质量上限由**原材料**决定——所以本模块最重要的纪律是：**没有合格的来源，就不往下写。**

## 先问清，再动手

动笔前必须问清：

1. **文体** —— 是独立发表的**综述文章**，还是原创研究论文的**引言**？两者目标不同：综述要系统覆盖并综合提炼；引言只为引出本文问题，不能喧宾夺主。
2. **研究问题**（一句话，越具体越好）与**范围**（学科、时间、语言）。
3. **纳入排除标准**。
4. **语料从哪来** —— 用户手上有哪些文献（PDF、BibTeX、Zotero/EndNote 导出、引文列表）？给谁看、投哪。

**信息不全就先问；尤其是语料，没有就先要，不要凭记忆开写。**

## 取料（Gate，分级可选）

本模块默认**无法自行访问文献数据库**。语料获取改为**分级可选**，不再一刀切：

1. **先问用户**：手上有没有现成文献（PDF / BibTeX / Zotero / EndNote 导出 / 引文列表）？**可选择性提供**，不强制。
2. **验料**：用户给了资料，先判断是否合理——是否一手来源、字段是否完整、有无疑似编造或互相矛盾。
   - 合理 → **以用户提供的资料为准**，建立文献台账往下走；
   - 不合理 → 指出问题（如混入百科/新闻、缺字段、出处可疑），请用户澄清或补充，不硬写。
3. **问是否补料**：资料不足或没给时，给用户一个选项——**"是否需要我额外搜集资料？"**
   - 需要且平台有检索工具 → 联网检索，逐条标注来源；
   - 需要但平台无检索工具 → 产出**可复制的检索式 + 待检索清单**（关键词、布尔逻辑、数据库、筛选条件），**停在这里等回填**；
   - 不需要 → 基于现有资料写作，明确标注哪些论断缺乏来源。

宁可交付一份"待检索清单"，也不交付一篇掺水的综述。

## 来源分级

只把**一手文献**当作事实性论断的依据：

| 等级 | 来源 | 可否作论据 |
|---|---|---|
| 一手 | 同行评审期刊 / 会议论文 / 学位论文 / 权威机构报告 / 标准 / 专利 | ✅ 直接引用 |
| 待定 | 高质量预印本（arXiv 等） | ⚠️ 可引，须标注"预印本，未经同行评审" |
| 禁用 | 百科、新闻报道、商业宣传、博客、自媒体、公司通稿 | ❌ 一律不作论据 |

**效率、寿命、占比等关键数字，必须来自一手文献或权威认证报告。** 找不到，就写明"未见来自一手文献的数据"，而不是拿新闻里的数字顶上。

## 每一步都要能回查

1. **界定问题** —— 复述研究问题与纳入排除标准，确认后再走。
2. **检索 / 取料** —— 交出可复制的检索式，或整理用户提供的语料；建立**文献台账**。
3. **逐篇抽取** —— 每篇抽到同一张表：研究问题、方法/样本、结论、局限。缺字段写 `未报告`，**不留空、不猜**。
4. **按主题归纳** —— 按主题、流派或方法聚类，别按时间罗列。每个主题写清：共识、分歧、证据强度。
5. **深挖机制，而非罗列数字** —— 演进要解释**为什么**：哪些机制在起作用、代表工作是什么、策略之间是竞争还是互补、成立条件是什么。能做**定量权衡**（如效率 vs 稳定性）的，附具体来源；没有定量的，明说证据不足。
6. **成文** —— 背景 → 主题 → 综合评述 → 研究缺口 → 本文定位。每个论断带引用标注，与文献台账一一对应。

提纲模板见 [`../assets/templates/review-outline.md`](../assets/templates/review-outline.md)。

## 红线

- **不编造。** 作者、年份、期刊、DOI、页码、效率数值，一律不能凭空写。
- **无来源不写。** 写不出可核验出处的论断，直接删掉，而不是标个占位继续写。
- **禁用来源。** 百科、新闻、软文、自媒体不得作为论据出现在正文或参考文献里。
- **不交半成品。** 成稿中不得出现 `[待补来源]`、`此处请补充` 之类占位——那是未完成，不是交付物。需要用户补的内容，**单列成一张清单**，别混进正文。
- **分清谁在说话。** 区分「原文献观点」和「归纳」。
- **有矛盾就写分歧**，不强行统一。
- **不照搬原句。** 综述成文对文献只做转述与归纳，执行 [`human-writing.md`](human-writing.md) 第 10 条「引用即转述」；正文与所引原文连续字段重合即重写。

## 产出与去向

交付综述正文、结构化文献台账、研究缺口清单、检索记录（检索式 + 日期 + 命中数）。文献台账交给 [`reference-format.md`](reference-format.md) 统一格式，正文交给 [`polish.md`](polish.md) 润色。
