# 模板复用（学校 / 期刊模板套用）

用户提供学校或期刊的模板 docx 时，**先解析模板、以模板为骨架生成正文**；无模板则本模块跳过，一切按 [`manuscript-format.md`](manuscript-format.md) 默认基线与 [`SKILL.md`](../SKILL.md) 第二步原样确认。

## 什么时候用

- 用户提供了模板（学校论文模板、期刊模板、组内统一模板）→ 本模块
- 用户没给 → 跳过本模块，按默认排版基线 + SKILL.md 七项选择题原样确认

## 第一步：先解析，再确认

进入需求确认**之前**先问一句"是否有学校/期刊模板 docx？"（用户消息已附带则直接解析）。解析四项：

1. **页面设置**：`sectPr`——纸张、页边距、页眉页脚（页码域）。
2. **样式**：`word/styles.xml` 中标题（Heading）与正文（Normal）的字体、字号、颜色。
3. **封面与前置页**：题目、作者、学号、院系等字段结构；页眉页脚样式。
4. **目录与章节骨架**：模板里已有的"目录"结构、章节占位（如"第一章 绪论"）。

**解析时必查三类脏数据**：

- **伪标题**：模板常用"普通段落 + 手动加粗放大"冒充标题，styles.xml 里的 Heading 定义可能与实际章节占位不一致——以**实际占位段落的格式**为准；两种说法对不上时，在确认题里说明并请用户定夺。
- **样式重定义**：Heading 被模板重定义（字号、字色与常规不同）属正常，按模板值记录，**不要"纠正"回默认基线**。
- **正文示例内容**：正文区的示例章节、"此处填写……"占位说明、示例图表**不是内容**——解析时标记为**待删除**，只保留章节骨架。

## 第二步：模板画像确认（点头后才生成）

把解析结果整理成一条清单**逐项复述**，等用户点头：

- **学到的版式**：页面设置、各级标题样式、封面字段结构、章节骨架；
- **将被删除**的示例内容（示例章节、占位说明、示例图表）；
- **被模板覆盖**的默认项（如"模板页边距 3cm，覆盖默认 2.5cm"）；
- **不会被模板覆盖**的学术底线项（见「可覆盖与不可覆盖」）；
- 字色、标题对齐这类模板与默认基线**打架**的项，**单独点出让用户拍板**，不静默选边。

**确认题规则（模板已定项）**：模板已定义的规格项不再让用户重新盲选——
- 陈述模板检测值：如"检测到模板要求：正文宋体小四、标题黑体三号、页边距上下 2.5cm 左右 3cm"；
- 选项：**A. 按模板执行（推荐按您使用模板值）　B. 改用其他（请补充）**；一项一条，逐项确认。
- 模板**未定义**的项照常出选择题，推荐值仍为默认基线。

## 第三步：套用生成

- **以模板为基础**：用 python-docx 打开模板文件，在保留封面、页眉页脚、样式的前提下，向正文区**替换**内容——**删除已标记待删除的示例内容，保留章节骨架**，写入真实内容；不要从空白文档重新搭。
- **优先级**：用户模板字体字号 > 默认排版基线；模板未定义的项才落到默认基线。
- **不破坏模板**：封面字段、页眉页脚、页码域框架保持原样。
- 若环境无 python-docx：解包 docx → 复制 `[Content_Types].xml`、`styles.xml`、`sectPr` → 只在 `document.xml` 的 body 中重建正文段落（保留 `<w:pPr>` 模板样式引用）。

## 可覆盖与不可覆盖

| 模板**可以**覆盖（按模板执行） | 模板**不能**覆盖（学术底线，照规范执行） |
|---|---|
| 字体、字号、页边距、行距、页眉页脚 | 公式必须 OMML 原生对象、编号居右 |
| 字色（模板彩色标题 → 确认题单独拍板） | 下标/上标必须真实格式（禁 `x_1` 伪下标） |
| 标题层级与编号样式（如"第一章"） | 正文引用编号右上角上标 |
| 章节骨架（章节划分与命名） | 参考文献一条一行、悬挂缩进、目标标准组成 |
| 表格线型（模板规定三线表则三线表） | 不编造文献/数据/DOI；中文正文用中文标点 |

## 第四步：验证

- 渲染成图检查：封面、页眉页脚、目录页码、标题样式与模板一致。
- `check_format.py --template 模板.docx` 跑一遍：**版式基准自动取模板实际值**（一级标题编号模式、标题对齐、模板字色、页边距一致性），模板合法偏离不再误报；学术底线项（伪下标、英文直引号、公式结构、上标、交叉引用、参考文献、目录）仍按规范校验。
- 交付格式仍遵守"唯一交付格式"约束。

## 边界

- 模板是"骨架"不是"内容源"：只复用版式，不抄模板里的示例文字。
- 模板样式与用户确认的排版规格冲突时，**模板优先**（用户明确要按模板做），且必须在模板画像确认时已向用户点明。
