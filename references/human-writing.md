# 语言规范（降重、降 AI 率）

写的时候注意降重、降 AI 率。总的来说：**有起伏、有变化、有突发性**——段落的长短、句子的长短、标点符号的使用、词语的搭配、句子的语法结构等都要有变化。不一定要选"最稳定最优"的写作方式，但要保证文段具有随机性：**根据上一句无法预测下一句一定接什么，根据上一个词无法推出下一个词会接什么**。

**适用范围**：整篇论文的正文写作、章节撰写，以及语言润色（见 [`polish.md`](polish.md)）都执行本规范。**前提是逻辑清晰、没有语病**——先保对，再求变。

## 九条规则

### 1. 高频表达替换

在逻辑清晰、没有语病的前提下，按需替换以下高频写法：

| AI 高频写法 | 替换为 |
|---|---|
| 在……的背景下 | 随着…… / 由于…… / 在……中 |
| 值得注意的是 | 直接陈述事实 / 一个关键发现是…… |
| 扮演着至关重要的角色 | 是……的关键 / 深刻影响了…… / 是……的基础 |
| 深入探讨 | 分析 / 研究 / 探讨 |
| 本文研究…… / 本文的目的是…… | 固定句式做变体，不要每次都用同一句式开头 |
| 非常 | 很 |
| 因此 | 所以 |
| 然而 | 但是 |
| 即便 | 虽然 |
| 因而 | 所以 |
| 此外 | 还有 |
| 于是 | 然后 |
| 可见 | 看得出 |
| 由此 | 这样 |
| 若非 | 如果不是 |
| 即使 | 就算 |
| 不久 | 很快 |

**替换目标本身也不许高频重复**（如"随着"同样属于 AI 高频词）：同一种写法在全文多次出现就再换别的表达，规则冲突时优先"变化"。

### 2. 删除或替换 AI 常用词汇

无论、随着、此外、首先、其次、然后、最后、比如、同时、也将、将为、例如、将成为、总的来说、总之 / 总而言之、以上、综上——能删就删，删不掉就换成更自然的说法。

### 3. 调整文章结构

AI 生成的是总分总结构或总分结构：先亮观点 → 再解释为什么 → 然后举例子 → 最后给观点做总结。**删除段落开头或结尾的总结句，对段落进行合并**，让结构不那么"标准"。

### 4. 控制段落长度（量化标准）

大模型生成的内容段落与段落之间字数非常相近。**必须按以下量化标准错落，不许"每段都差不多长"**：

- **相邻段落字数差 ≥30%（或至少差 40 字）**：相邻两段不允许近似等长；不达标就合并或拆分段落后重写。
- **段长三档交替**：短段（≤120 字）、中段（120~300 字）、长段（≥300 字）全文交替出现；**不得连续 3 段落在同一档，也不得全部挤在中段**。
- **句长错落**：每段至少 1 个长句（≥40 字）+ 1 个短句（≤15 字）交替；段落内部句长明显起伏，不连续同长。

### 5. 优化内容逻辑

避免"提出观点 + 举例 + 总结"的固化模式，规避总分 / 总分总等高 AIGC 率结构，**不让开头就暴露后续展开方式**。

### 6. 修正语法习惯

给无主语句补上主语并前置，短句合并为长句。例：

- "随着技术的不断进步" → "在 AI 技术不断进步的今天"
- "通过准确的提示" → "AI 能够通过准确的提示"

### 7. 避免动词名词化

把被动句 / 名词化结构改成主动句，加入主观判断：

- "对数据进行分析" → "分析数据"
- "对计划进行调整" → "调整计划"
- "对方案进行评估" → "评估方案"

### 8. 配上具体例子或说明

避免纯理论、空洞、凑字数的表达；关键论断尽量落到具体例子、数据或说明上。

### 9. 少用或不用括号、破折号、冒号

能用陈述句说清楚的就不用括号补充、不用破折号插入、不堆冒号列举。

## 交付前自查

写完后逐段过一遍：

1. 运行 `scripts/check_style.py` 检查：相邻两段字数差是否 ≥30%（或 ≥40 字）？是否出现连续 3 段同档、全部挤中段？不达标就合并 / 拆分段落后重跑。
2. 段落是否删掉了"总分总"式的开头总结句 / 结尾总结句？
3. AI 高频词（第 2 条清单）是否清理干净？替换后的表达是否又在高频重复？
4. 同一个连接词、同一个句式是否在全文反复出现？
5. 随便挑一句，能否从上一句直接预测出来？能，就重写这两句。

## 红线

- **变化不等于出错**：逻辑清晰、无语病是前提，不许为降 AI 率牺牲准确性。
- **数据、术语、引用不受本规范影响**，一律保持精确与统一。
