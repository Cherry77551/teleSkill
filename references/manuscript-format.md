# 论文排版规范

内容再好，排得乱也扣分。这里给一套**通用排版基线**，并规定**交付前先问清输出形态**。

## 先问输出形态（动手前）

生成任何成稿前，一次问清两件事：

1. **输出格式**：
   - **Word（`.docx`，可编辑）** —— 还要继续改、可能被要求改格式 → 默认
   - **PDF（定稿）** —— 已定版，要交存档或打印
   - **其他** —— Markdown / LaTeX（投某些期刊或排版工具链）
   （注：`.docx` 就是 Word 格式，两者是一回事。）
2. **附带要素**：要不要**表格、插图、目录、公式、封面 / 标题页、附录**？要就一并规划。

## 排版基线（未指定期刊时）

若用户给了目标期刊（如 **Nature**）的投稿指南或模板，**以它为准**；没给，用下面的通用基线：

- **正文**：中英文混排统一；英文用 Times New Roman 一类衬线字体，中文用宋体 / 黑体；字号 10–12 pt；行距 1.5 或期刊要求；两端对齐；页边距对称。
- **标题层级**：编号与层级一致（1 / 1.1 / 1.1.1），不跳级。
- **数字与单位**：数字与单位之间加空格；量纲用国际单位；缩写首次出现给全称。
- **图表**：编号 + 标题 + 图注，图注独立成句，使图脱离正文也能读懂（见 [`data-viz.md`](data-viz.md)）。
- **参考文献**：**每条独占一行**，按目标格式（默认 GB/T 7714）排序；用**悬挂缩进**；正文引用与文后条目一一对应（见 [`reference-format.md`](reference-format.md)）。

## 交付前校验

Word / PDF 一律**渲染成图逐页检查**（见 [`docx.md`](docx.md)），确认：字体、字号、行距、标题层级、图表编号、**参考文献每条一行且悬挂缩进**、目录页码。

## 红线

- **参考文献不许堆成一坨。** 一条一行、悬挂缩进；混排或换行错乱视为不合格。
- 说"参照 Nature"就按它的格式（如 `Nature 605, 45–50 (2022)`），不要自己发明。
