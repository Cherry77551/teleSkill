# 论文排版规范

内容再好，排得乱也扣分。本文件是**排版规格的唯一定义处**：默认基线、公式与符号规范、交付前校验口径。需求确认的**流程与选择题措辞**以 [`SKILL.md`](../SKILL.md) 第二步为准，本文件不再重复。

## 动手前：先完成需求确认

生成任何成稿前，先按 [`SKILL.md`](../SKILL.md) **第二步**完成七项选择题（输出格式、摘要、附带要素、排版规格、论文结构、篇幅、资料来源）与三步收尾（汇总复述 → 预估时间 → 等用户点头），未确认前禁止动笔。**确认的输出格式即唯一交付格式**；确认的排版规格即**硬约束**，按下方基线逐项落实。

## 排版基线（默认规格）

若用户给了目标期刊（如 **Nature**）的投稿指南或模板，**以期刊要求为准**，覆盖下表对应项；没给，用下面的默认规格：

### 页面与字体

| 项 | 规格 |
|---|---|
| 页边距 | 四边 2.5 cm |
| 正文中文字体 | 宋体 |
| 正文西文字体 | Times New Roman |
| 正文字号 | 小四（12 pt） |
| 标题字体 | 黑体（各级标题统一，与正文宋体**严格区分**） |
| 字体颜色 | **全文纯黑色**（含正文、标题、表格、图注、页眉页脚），禁用彩色 / 主题色 |

**字体硬约束**：正文用正文字体（如宋体小四），各级标题用黑体，**严禁整篇混用同一种字体**（如正文被排成黑体）。

### 标题层级与对齐

| 层级 | 编号 | 字体 | 字号 | 对齐 |
|---|---|---|---|---|
| 论文题目 | — | 黑体 | 二号或按用户要求 | **居中** |
| 一级标题（章标题） | **一、二、三……** | 黑体 | 三号（16 pt） | **居中** |
| 二级标题 | 1.1 | 黑体 | 四号（14 pt） | 左对齐（顶格） |
| 三级标题 | 1.1.1 | 黑体 | 小四（12 pt） | 左对齐（顶格） |

**一级标题编号用中文数字“一、二、三……”**（如“一、绪论”），不用“1”或“第1章”；二级用 1.1、三级用 1.1.1，编号与层级一致，不跳级；用户模板另有规定则按模板。**论文题目与章标题必须居中**，不得左对齐。

**标题长度**：各级标题尽量不超一行（约 30 字）；超长标题必须精简后再使用。

### 段落

| 项 | 规格 |
|---|---|
| 行距 | 1.5 倍 |
| 对齐 | 两端对齐 |
| 首行缩进 | 2 字符 |
| 段前 / 段后 | 不空行 |

### 目录

**目录单独占一页**：目录前加分页符从新页开始，目录结束后再加分页符，正文另起新页；**目录不得与封面、摘要或正文混排在同一页**。目录抓标题层级自动生成，页码与正文一致。

### 数字与单位

数字与单位之间加空格；量纲用国际单位；缩写首次出现给全称。

### 标点符号

**中文正文一律使用中文标点**：引号用“”‘’、书名号《》、逗号，、句号。、顿号、、括号（）等全角标点；**严禁在中文句子里用英文直引号 " '**或半角标点。英文标点只出现在英文句子、公式、代码内。

### 图表

编号 + 标题 + 图注，图注独立成句，使图脱离正文也能读懂（见 [`data-viz.md`](data-viz.md)）。

### 表格

- **行高、列宽按内容实际情况确定**：文字长的列放宽、数字列收窄，行高随内容自适应，**整体美观协调**，不挤不空。
- **表类型按用户确认执行**：注明**三线表** → 顶线、底线较粗 + 表头下栏目线较细，**无竖线**；未注明 → **正常全线表格**（全边框）。
- 表题编号置于表格上方居中，表内字号可比正文小一号。

### 变量与符号

- **变量一律用斜体**（含希腊字母 ω、η、δ 等）；数字、单位、下标文字用正体。
- **下标/上标必须是真实格式**：禁止下划线 `_` 伪下标——**包括表格符号列**（如 ω_i、η_ch、δ_ij 必须写成真实下标）。
- 表格内符号与正文同规范。

### 公式

- 公式必须用 **Word 原生公式对象（OMML）** 渲染：上下标、分数、根式、求和等结构用公式语法表达，**禁止用纯文本平铺、Unicode 字符拼接或截图伪装**。
- **公式本体居中、编号靠右**：编号用 (1)、(2)，排在公式行右端（公式行用“居中 + 右对齐制表位”排版）。
- **公式渲染必须正确**：生成后渲染成图**逐个检查**每个公式——分数上下位置、上下标位置、根式与求和结构显示完整；出现乱码、平铺文本、结构错位即不合格，修复后重新生成再交付。
- **符号说明规范：公式符号（含“式中……”符号说明、正文变量名）的下标/上标必须用真实下标/上标格式**（OMML 下标结构或 Word 下标、上标格式）；**禁止用下划线 `_` 平铺表示**（如把 x₁ 写成文本 x_1）。
- 正文引用写作“式(1)”。

### 参考文献

**每条独占一行**，用**悬挂缩进**；正文引用编号用右上角上标（如"……的方法[1]"），不得与文字平排；条目组成按 GB/T 7714-2015 标准，**不得自创字段顺序或标点**——完整组成表见 [`reference-format.md`](reference-format.md)「每条条目的标准组成」。

## 交付前校验

1. **程序化校验**：运行 `python scripts/check_format.py 论文.docx --strict`（学位论文 / 完整稿件；短文 / 片段用默认模式，公式、上标、目录、一级标题缺失不算错），FAIL 项修复后重新生成再跑。
2. **渲染抽查**：`render_check.ps1` 转 PDF 后**只抽渲染公式所在页、目录页、首页/尾页**，不逐页全量渲染（口径与 [`docx.md`](docx.md)「效率纪律」一致）；检查点清单见 [`docx.md`](docx.md)「交付前渲染看一眼」。
3. **任何一项与用户确认的规格不符即不合格**，返工重排后再交付。

## 红线

- **排版规格与用户确认不符 = 不合格**（如确认宋体小四却整篇黑体、字色非黑、题目 / 章标题未居中、目录未独占一页、正文引用未上标），返工重排后再交付。
- **参考文献一条一行、悬挂缩进**，混排或换行错乱视为不合格（详见 [`reference-format.md`](reference-format.md)）。
- 说"参照 Nature"就按它的格式（如 `Nature 605, 45–50 (2022)`），不要自己发明。
