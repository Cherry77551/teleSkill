# 参考文献排版

引用乱，审稿人第一眼就皱眉。这里把散落的引用统一成**一种格式**，并保证正文与文后一一对应。

## 先问清，再动手

先确认目标格式：GB/T 7714（中文期刊 / 学位论文，**默认**）、APA 7、IEEE、Nature 等；以及文献从哪来（粘贴文本 / BibTeX / Zotero / EndNote / docx 域代码）。**格式不定，先问。**

## 每一步都可回查

1. **定格式** —— 明确目标标准，给出该标准的 1 条样例让用户确认。
2. **解析** —— 把每条引用拆成字段：作者、题名、载体、年、卷、期、页、DOI。
3. **补全** —— 缺字段列入**待补清单**；能查证的提议补全，**经用户确认后才写入**。
4. **去重** —— 同一文献的不同写法合并，保留信息最全的一条。
5. **输出** —— 生成文后参考文献表，按格式排序；正文引文与表一一对应。
6. **校验** —— 产出 `.docx` 后按 [`docx.md`](docx.md) 渲染成图，核对**每条一行、悬挂缩进**、**正文引用编号为右上角上标**、排序与分页；确认正文引用数 = 文后条目数（[`../assets/checklists/reference-checklist.md`](../assets/checklists/reference-checklist.md)）。

批量排版可用 [`../scripts/format_refs.py`](../scripts/format_refs.py)：读结构化 CSV / BibTeX，`--format gbt|apa|ieee|nature` 指定目标格式（默认 GB/T 7714），只做确定性排版，不补全、不编造。

## 每条独占一行

参考文献表**一条一行**，用**悬挂缩进**（首行顶格、续行缩进 2 字符）：

```
[1] 张三, 李四. 一种方法[J]. 期刊名, 2023, 46(3): 45-58.
[2] 王五. 专著名[M]. 北京: 科学出版社, 2021.
[3] Chen W, Li M. A reproducible figure pipeline[C]. Proc. of VIS, 2020: 120-128.
```

**最常见的排坏方式**：把所有条目连在一行或挤成一整段。**一条一行是硬要求。**

## 每条条目的标准组成（GB/T 7714-2015）

**条目的组成顺序与标点都是硬格式，不得自创**，按载体类型撰写（半角标点）：

| 载体 | 标准组成 | 示例 |
|---|---|---|
| [J] 期刊 | 作者. 题名[J]. 刊名, 年, 卷(期): 页码. | `[1] 张三, 李四. 一种方法[J]. 电学学报, 2023, 46(3): 45-58.` |
| [M] 专著 | 作者. 书名[M]. 出版地: 出版社, 年: 页码. | `[2] 王五. 电网调度[M]. 北京: 科学出版社, 2021: 12-30.` |
| [D] 学位论文 | 作者. 题名[D]. 保存地: 保存单位, 年. | `[3] 赵六. 智能体协同调度研究[D]. 北京: 华北电力大学, 2022.` |
| [C] 会议 | 作者. 题名[C]. 会议名, 出版地: 出版社, 年: 页码. | `[4] Chen W, Li M. Pipeline[C]. Proc. VIS, 2020: 120-128.` |

- 作者 >3 列前 3 加"等"（中文）/ "et al."（西文）；
- 缺失字段留空或列入待补清单，**绝不编造、绝不换顺序**；
- 批量生成用 `scripts/format_refs.py`（支持 CSV 与 BibTeX，GB/T 7714 按载体类型输出标准组成；APA / IEEE / Nature 用 `--format` 切换，作者名按输入原样不改写缩写）。

## 常见格式要点

- **GB/T 7714** —— 作者 ≤3 全列，>3 列前 3 加"等 / et al."；`[J]/[M]/[D]/[C]` 标识载体；正文引用编号 `[1]` 用**右上角上标**（superscript），紧贴被引文字，不得与正文平排。
- **APA 7** —— 作者-年制，正文 `(Author, 2020)`，文后悬挂缩进。
- **IEEE** —— 数字制 `[1]`，按正文首次出现顺序编号。
- **Nature** —— 数字制；如 `Author, A. B. et al. Title. Nature 605, 45–50 (2022).`

## 红线

- **不编造 DOI、页码、卷期。** 查不到的字段列入**待补清单**，不进正式表，也不留 `[待补来源]` 占位。
- **非学术来源不进正式表。** 百科、新闻、商业宣传、自媒体不得混入参考文献列表；用户坚持引用时，单列"非学术来源"并注明。
- **一条一行、悬挂缩进。** 堆成一坨 = 不合格。
- 正文引用数 = 文后条目数，缺一不可。

## 产出与去向

交付格式化参考文献表（`.docx` 优先，生成与校验见 [`docx.md`](docx.md)）+ 正文引文标注；整篇排版见 [`manuscript-format.md`](manuscript-format.md)。若同时要改正文语言，交给 [`polish.md`](polish.md)。
