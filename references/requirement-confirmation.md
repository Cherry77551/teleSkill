# 需求确认（七项选择题 + 三步收尾）

本文件是 [`SKILL.md`](../SKILL.md) 第二步的完整展开。**未完成本流程并得到用户明确点头前，禁止动笔。**

## 硬约束

- **可点击选择题优先**：平台有提问工具时，每项做成一道选择题——选项标题简短、说明放选项描述里，用户**点选即答**；需要补充的（字数、表类型、自定义字体）用提问工具自带的**自定义输入**让用户**对选项做补充**，不要让用户打字复述选项。
- **每项写明默认行为**，措辞统一为"**若不选择或无要求，推荐按您使用 XX**"；**禁止**孤零零标"（默认）"，**禁止**"您习惯使用 XX"的口吻。
- **无提问工具时**才退化为文本编号选项（A/B/C + 说明），并注明"也可直接回复您的自定义要求"。
- **数值项先选后填**：字数、页数等先让用户点选（按字数 / 按页数 / 不做要求），选中后再请用户报数值或范围，并提醒一般不严格卡死。
- ❌ 反例："摘要要吗？篇幅多少页？"（开放式填空 = 不合格）；"C. 不做要求（默认）"（孤立默认标注 = 不合格）。

## 模板先行

确认开始前先问是否已有学校 / 期刊模板 docx（用户消息已附带则直接解析）。

- **有模板**：先按 [`template-reuse.md`](template-reuse.md) 解析并产出模板画像，再进入下列确认。模板已定义的规格项（字体、字号、页边距、行距、页眉页脚、章节骨架）改为**确认题**——陈述模板检测值（如"模板要求正文宋体小四"），选项："按模板执行（推荐按您使用模板值）/ 改用其他（请补充）"，**不让用户重新盲选**；模板未定义项照常出选择题。
- **无模板**：按 1~7 原样进行。

## 七项确认

1. **输出格式**：A. Word 文档（可编辑）　B. PDF（定稿）　C. LaTeX　D. HTML　E. 其他。若不选择或无要求，推荐按您使用 Word 文档（可编辑）。
2. **摘要**（四选一，必须含"不要摘要"）：A. 中文摘要 + 英文摘要　B. 仅中文摘要　C. 仅英文摘要　D. **不要摘要**。若不选择或无要求，推荐按您使用"中文摘要 + 英文摘要"。
3. **附带要素**（逐项"要 / 不要"，不要笼统问"要不要附件"）：表格（要 / 不要；表类型：A. 全线表格　B. 三线表，若不选择或无要求，推荐按您使用全线表格）、插图、目录、公式、封面 / 标题页、附录，每项都让用户点选。
4. **排版规格**（逐项选择题，禁止开放式填空；每项写明"若不选择或无要求，推荐按您使用 XX"；**必须逐项确认，不允许跳过**）：
   - 中文字体：A. 宋体　B. 黑体　C. 楷体　D. 其他 → 推荐按您使用宋体
   - 西文字体：A. Times New Roman　B. 其他 → 推荐按您使用 Times New Roman
   - 正文字号：A. 小四 12pt　B. 五号 10.5pt　C. 四号 14pt　D. 其他 → 推荐按您使用小四 12pt
   - 标题字号：推荐按您使用一级黑体三号 / 二级黑体四号 / 三级黑体小四
   - 页边距：推荐按您使用四边 2.5cm
   - 行距：推荐按您使用 1.5 倍

   用户给了期刊排版要求则以其为准。确认后即为**硬约束**：字体分设（正文宋体小四、标题黑体，严禁混用）、全文纯黑、题目与章标题居中、目录独占一页、引用右上角上标；完整排版基线（页边距、行距、标点、表格、公式、参考文献等）见 [`manuscript-format.md`](manuscript-format.md)「排版基线」，生成前先读。
5. **论文结构**：把 [`../assets/templates/paper-structure.md`](../assets/templates/paper-structure.md) 的方案清单做成选择题（学位论文 / 期刊论文 / 独立综述 / 课程论文 / 开题报告 / 用户自带模板），可组合；用户不选 → 按主题推荐一套再询问"是否合理"。
6. **篇幅**（三选一）：A. 按字数设定　B. 按页数设定　C. 不做要求。若不选择或无要求，推荐按您使用"不做要求"（按内容完整度来写）。用户选 A 或 B 后，**再**请用户报数值或范围（如 8000~10000 字、10~15 页），并提醒一般不严格卡死；**禁止不选就直接让用户报字数页数**。
7. **资料来源**：A. 我有现成资料（PDF、BibTeX、Zotero / EndNote 导出、引文列表）　B. 没有资料，请你联网搜集并逐条标注来源　C. 没有资料，先给我检索式 + 待检索清单我自己查。若不选择，推荐按您使用 A（先提供手上的资料，没有也行）。选 A：先判断资料是否合理，合理则**以用户资料为准**，不合理就指出问题请澄清；选 B：平台有检索工具且用户同意才联网搜集并逐条标注来源；选 C：产出**检索式 + 待检索清单**并停下等回填。

## 语言（内部判定，不单独提问）

不设"语言题"，按 [`english-writing.md`](english-writing.md)「语言判定」信号表判定：用户明说、英文期刊模板 / 目标国际期刊、引用格式选 APA / IEEE / Nature → 英文；无任何英文信号 → 中文。

- 判定**中文**：不询问、不出现在选择题与汇总复述中。
- 判定**英文**：不单独发问，但在汇总复述写明"本次按英文写作执行"并附判定依据，随全部要求一起等用户点头。

## 三步收尾（强制执行）

1. **汇总复述**：把全部输出要求（输出格式、摘要、附带要素含表类型、字体字号规格、论文结构、篇幅；英文稿另附语言判定依据）**汇总成一条清单逐项复述**，不要只问一句"这样可以吗"。
2. **预估完成时间**：根据篇幅与任务复杂度给出预计完成时间。
3. **等用户点头**：最后询问"**以上还有什么需要修改的地方吗？没有的话请点个头，我将开始写**"。**必须看到用户明确肯定（点头 / 可以 / 开始）后才动笔**；用户提出修改就先改再重新确认；得不到肯定前，一个字都不要写。
